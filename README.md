Hipotsesis

La implementación de un sistema basado en un microcontrolador ESP32, un módulo de posicionamiento global (GPS) y la integración con una API de WhatsApp permitirá la transmisión automatizada y en tiempo real de la ubicación geográfica exacta (enlace de Google Maps) hacia un número telefónico predefinido en un tiempo de respuesta menor a 15 segundos tras la activación física de un pulsador de emergencia.
